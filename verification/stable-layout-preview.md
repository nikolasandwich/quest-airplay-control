# 0.2.13 固定校准布局

用户已在 iPad 打开0.2.12底板，反馈顶部提示换行伴随画面抖动，要求步骤直接放在页面里并简化入口。

## 修复

原生状态 TextView 原为 wrap_content；内容变长会挤压下方按权重分配的投屏区域。fitVideo 尺寸变化分支会取消观察、重设射线输入及视频/射线布局。0.2.13 改为固定一行高度（lineHeight + padding），省略显示的完整状态可在校准入口查看。校准时顶栏只显示进度，主要步骤直接显示在 iPad 底板固定区域。不额外添加详情栏挤占视频。

底板顶部固定3%位置/24%高度，底部固定2%位置/8%高度；指示文字和详细状态各在自己的固定空间内，超长详情可滚动阅读。圆环半径随视口高度限制，中心范围38%–78%，与提示区避让。首次取得基线后，同一步失去/恢复基线不重新放置目标；新步骤及实际视口尺寸变化可重新放置。网页最初收到指针事件时仍允许一次建立基于指针的目标位置。

统一校准对话框包含首次打开地址、Safari收藏说明、复核周期、完整当前状态和开始按钮。已打开底板可直接开始，之后看同一投屏页面操作。首次仍需在iPad打开一次；现有AirPlay接收/BLE鼠标通路没有可靠打开指定URL的实现。头显内二维码不便iPad扫描，未作为主入口引入。没有盲发键鼠、独立iPad应用或公网部署；地址改变时收藏需更新。
