# 0.2.17 应用内语言选择

基于已安装0.2.16增加应用语言入口，版本code24、0.2.17-language-picker-preview。入口：点应用顶部状态栏，打开帮助面板，选择“语言 / Language”。可选跟随系统、English、Deutsch、Français、简体中文；点击应用后保存选择。

默认仍跟随系统，未支持语言回退英文。显式选择保存于应用私有偏好，不修改系统Locale、配对或其他应用。AppText基于应用配置副本创建翻译资源；选择跟随系统时重新使用系统资源。系统语言后来变化也不会覆盖显式选择。服务刷新翻译和通知，说明网页随/state语言字段变化；蓝牙服务不重启。桌面启动图标的系统管理名称仍按系统资源显示。

切换时撤销控制授权、清理本地射线状态并重建Activity，窗口会短暂刷新；用户需要重新启用控制。没有自动移动/点击，取消已有按下动作只沿用必要的松开机制。没有把语言选择写入上次控制状态而自动重新启用。

72项本机测试全部通过。新增4项Robolectric测试覆盖：全部语言偏好保存及资源桥接重新初始化、系统语言不受影响、系统改变不覆盖显式选择、恢复跟随系统、非法选择不损坏偏好、从真实帮助按钮进入语言对话框并选择英文。首轮界面测试需要推进暂停的主线程队列以执行Dialog按钮回调；修正测试等待后全套通过。

四套136资源键、格式参数及自动生成英文回退检查通过；原说明网页5种地区语言HTTP失联回归通过。APK/Android测试APK构建成功，lint 0错误。未在头显切换或安装本候选，尚未推送；0.2.16安装包保留。安装前同步中断窗口。
