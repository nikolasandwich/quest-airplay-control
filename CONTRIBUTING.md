# Contributing

Reports, translations, documentation and focused fixes are welcome. Include version,
device/OS, reproduction and expected/actual behavior. Remove private captures,
credentials and device addresses. Contributions use GPL-3.0-or-later; preserve
original notices and identify the origin/license of imported code. No extra CLA.

Run README build/test/lint commands. Input and lifecycle changes should test
cancellation, stale callbacks and recovery. Arrange physical input tests with the
device owner. Synthetic tests cannot establish real-headset reliability.

Do not commit signing keys, account exports or raw logs. See SECURITY.md.
